# 内心岛屿

一座关于生活、偏爱、记忆与想象的个人数字空间。它不是电子简历，而是一张会随着主人持续生长的生活潮汐图。

## 本地预览

这个站点没有构建步骤或外部运行依赖。可以直接打开 `index.html`，或在目录中运行任意静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 发布

仓库根目录就是完整的 GitHub Pages 产物。将默认分支的 Pages 来源设置为根目录即可。

## 替换真实内容

- `index.html`：所有正文、“此刻”、兴趣、时间坐标、未来清单和联系方式。
- `script.js`：兴趣切换内容与随机生活纸片。
- `.photo__visual`：显影室的 CSS 占位画面。加入真实照片后，可用 `<img>` 替换对应的 `span`，保留现有尺寸与交互。
- `assets/og-card.png`：社交分享封面。

## 无障碍与性能

- 语义化 HTML、跳转链接、可见键盘焦点、按钮状态与原生对话框。
- 支持 `prefers-reduced-motion`。
- 无框架、无远程字体、无图片依赖；视觉主要由 CSS 与 SVG 生成。

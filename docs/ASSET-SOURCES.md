## 序幕肖像

- [Wikimedia Commons: Fyodor Dostoyevsky (Doss, 1876).jpg](https://commons.wikimedia.org/wiki/File:Fyodor_Dostoyevsky_(Doss,_1876).jpg)
- 摄影：尼古拉·多斯（页面署名 Н. Досс），1876。
- 原图 800 × 1280；Commons 标注 Public Domain，PD-old-70-expired，美国 1931 年之前发表。
- 原始来源：[陀思妥耶夫斯基照片档案](https://fedordostoevsky.ru/photoarchive/photos/)。
- 本机直连 Wikimedia 下载超时，使用 images.weserv.nl 传输同一公开文件（未传送私有数据），随后在本地生成 480 / 800 WebP 并去元数据。正式网站只加载本地派生文件，不依赖该传输服务。
- 黑白、亮度、暗部融合由 CSS 完成；没有 AI 重绘或伪造摄影。

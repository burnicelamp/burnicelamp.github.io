# 歌词来源调查与实现边界

核对日期：2026-09-10。当前仓库未提供歌词授权文件、私有后端或歌词 API 凭证。

1. Apple Music / MusicKit：[官方 Song 文档](https://developer.apple.com/documentation/musickit/song)暴露 hasLyrics 可用性标记，这并不是歌词正文或同步时间轴接口。本次查阅的公开 API 中未找到可用于本站的歌词正文授权接口。保留官方嵌入试听和链接，不抓页面或调用私有接口。公开 iframe 没有本项目可依赖的播放时钟，不模拟自动同步。
2. Musixmatch：[官方发布的 Lyrics API 文档](https://www.postman.com/musixmatch-dev/musixmatch-apis/documentation/pqm8o6w/lyrics-api)包含歌词、同步字幕接口，要求 API key 保密。响应包含版权署名、追踪地址和地域限制。[官方 SDK](https://github.com/musixmatch/musixmatch-sdk)要求遵循 API 条款。接口存在不代表本站已取得展示和缓存分发权限。没有已核实授权与私有后端，不能把密钥或完整 API 响应直接放入 GitHub Pages。
3. 决策：本次不激活 Musixmatch，不声称已取得授权；不使用来源不明歌词聚合站。组件只接受站主自有、直接授权或公版且允许静态公开分发的数据。API 提供商内容不能仅通过改一个来源名字伪装成直接授权。

后续若签约 Musixmatch，先按当时合同确认域名、地区、曲目版本、全文/同步额度、缓存和署名规则；由私有服务保管密钥并按访客地区过滤限制，展示响应要求的版权、官方品牌署名与回链，按约执行展示追踪和到期清除。不要描述成“填个 key 即可”。官方文档主页在本次环境中无法直接打开，未把无法核实的套餐条件写成事实。

组件已有三种状态：无可展示歌词时显示曲目和平台入口；有授权歌词但无时钟时完整自由阅读并署名；有授权时间轴与合法音频时钟时支持逐句高亮、容器内居中、seek、暂停、片段偏移、手动点击恢复跟随、键盘和触屏。

回归中的文字与静音音频均临时生成，只用于测试，不向正式数据写入第三方歌词或音频。

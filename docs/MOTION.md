# 材质与动效 · 2026-09-14

动效服务于物件的重量、纸张厚度与空间进入感，正文和主要操作保持稳定。

- 声场：精细鼠标指针下，唱片封套最多旋转 X 3° / Y 4°，伴随很弱的表面反光。移开、滚动、窗口失焦或进入弹层时回到原位。图片失败时的专辑文字封套也可自然使用。
- 书页：有真实封面图片时，鼠标悬停产生 5° 翻起与 3px 轻抬。书内正文、分页和切书按钮不参与倾斜。
- 空间：声场、真实电影/书目、记录初次进入视口时轻移 12px、520ms 显现。同一 DOM 节点只显现一次，回看不重复。空房间保持静态；照片沿用已有显影与放大转场，仅增强悬停/键盘焦点边缘。

新增 js/motion.js 与 motion.css，无运行依赖、无 WebGL、无持续渲染循环。指针更新按 requestAnimationFrame 合并；视口进入由 IntersectionObserver 驱动。内容默认可见，动画无需等待即可操作。

触屏不启用鼠标倾斜；prefers-reduced-motion 禁止材质旋转并立即取消正在进行的显现。测试使用 Edge 桌面与手机模拟，验证了偏好动态切换、弹层复位、一次性显现和现有完整浏览回归。书封夹具只存在于测试路由中。

运行：node tests/motion-check.cjs。与现有测试一样可设置 PLAYWRIGHT_MODULE / BROWSER_CHANNEL / SCREENSHOT_DIR。

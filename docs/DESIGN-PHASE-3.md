# 第三阶段：黑暗中的私人收藏

以序幕肖像的明暗关系作为世界的起点，声场由唱片及真实播放器尽早接管；银幕以宽画框留黑及边缘下一帧形成投影空间；书页以纸张、中缝、厚度与可读的短评形成停留；暗房按胶卷主图、横竖比例和结束帧编辑；记录回到连续阅读。

保留原生 ES Modules、JSON 内容、现有歌词时钟、来源许可验证、导入工具、作者书签、搜索语法与放大转场。无新增运行依赖。视觉变化与交互统一在现有组件中，新增 journey.js 仅管理分享、会话和弹层历史。

手机默认阅读书名、作者与感受，书内分页和换书分别操作；声场不再插入空歌词。真实收藏为空的房间保持完整构图但不制造条目和计数。测试夹具验证 80 本书、多段长文字、横竖混合照片与历史返回，不将其发布为收藏。

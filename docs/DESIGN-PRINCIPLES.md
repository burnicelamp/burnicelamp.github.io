# BURNLAMP 设计宗旨

以下三条是所有视觉、交互与内容实现的最高设计约束。新增或调整任何板块时，应先说明它如何同时满足三条宗旨；不能只靠换颜色、加阴影或延长动画来声称完成设计。

## 1. 高级

结果必须像为 BURNLAMP 的内容与空间专门设计，而不是粗糙、普通、劣质或套用模板。高级来自原创的信息层级、准确的比例、克制的材质、精细的排版与完整的边界状态；每项装饰都要服务内容，不以堆效果替代判断。

## 2. 智能

界面应主动理解任务而不是呆板执行：核心功能完整，同一任务不重复堆控件，状态和导航可理解、可恢复、可打断。默认覆盖键盘、触屏、慢网、加载失败、连续操作、减少动态效果、深链接和浏览器前进／后退，并为内容规模增长保留稳定结构。

## 3. 大气

真实内容是画面的主角。通过宏大的画面尺度、清楚的空间关系、从容的留白和有节奏的动效建立冲击力，让人在桌面与手机上都感到完整、壮观、值得停留。大气不是把所有元素放大，也不是夸张运动；它要求主次坚定、画面舒展、操作退后。

## 决策检查

- 是否保留了全站既有色彩、字体气质与空间叙事？
- 是否产生了明确的信息结构或交互提升，而非表面修饰？
- 是否用真实内容验证桌面、手机和异常状态？
- 是否仍保持原生、轻量、可维护，并避免依赖堆叠？
- 是否保留稳定 ID、来源、搜索、深链接、历史导航与无障碍能力？

若三个宗旨之间出现冲突，优先顺序不是牺牲功能换视觉，而是重新简化结构，让完整功能在更清楚、更从容的界面中成立。

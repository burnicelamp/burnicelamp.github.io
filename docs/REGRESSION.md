## 本轮结果

- 用正式域名的真实桌面 1440×1000 与手机 390×844 页面完成改前审视；本地再检查 320、390、768、980、1440 五档宽度，银幕和书页均无水平溢出。
- 四部影视共 12 张图片全部使用真实横版 16:9 素材。逐 URL 实际请求均返回 200，浏览器解码宽度 1920—3840px，与 `content/cinema.json` 声明一致；来源和署名见 `docs/CINEMA-BOOKS-SOURCES.md`。
- 银幕主画面不含站点文字或控件；片内换图、跨作品切换和片目各自只有一种语义。延迟、失败、重试、连续反向操作和直接选片均保留当前画面，以最后一次操作为准。
- 作者目录用内存夹具验证至 100 位作者；作者展开不自动跳书，搜索、空结果、返回全部、键盘 Enter、Escape、焦点归还和手机全屏目录通过。
- 长标题、无摘句、长正文、首尾书目与 100 位作者均不截断正文、不产生书页内滚动。手机为自然单页，桌面为书名页＋阅读页，不重复简介。
- 深链接、浏览器前进／后退、触摸横滑与纵向手势区分、键盘、动态减少模式、图片失败恢复和内容源单独失败均通过；浏览器控制台无新增未捕获错误，本地资源无 404。
- `cinema-books.css` 是两个新版组件唯一的样式入口；根类改为 `cinema-room` / `reading-room`，不再与 `styles.css` 中历史组件规则形成覆盖链。

## 执行命令

- `node tools/build-search.mjs`
- `node tools/validate-content.mjs`
- `node tests/content-check.mjs`
- `npm run test:browser`（基础浏览器回归、专项交互回归和动效回归）
- `node tools/verify-cinema-media.cjs`（需要网络，用于核对 12 张外部图片的实际响应与像素尺寸）

`tools/review-capture.cjs` 生成桌面／手机的银幕、书页和目录截图；`tools/review-record.cjs` 记录换图、直接选片、书页与作者目录的真实交互过程。正式内容没有写入压力测试作者或长文夹具。

## 仍有边界

TMDB 图片为外部引用，已验证当前可达但不能保证第三方永久托管；失败时界面会保留现有画面并给出重试。桌面 Edge 和手机触屏视口模拟已验证，尚未在实体 iPhone Safari 与实体 Android 浏览器上执行本轮验收。本节原始验收结论在发布前产生；后续授权发布状态见本文档顶部。

- 修改前用真实 Edge headless 浏览正式域名，保存桌面 1440×1000、手机 390×844 首屏和声场截图；确认是当前 main 的六空间版本。
- 本地正式内容六空间分别截图，再按截图修正唱片比例、手机分享按钮遮挡、初次访问状态以及长文内页操作的位置。
- node tools/validate-content.mjs、node tests/content-check.mjs：真实内容、数据结构、许可边界、搜索、关联、歌词时钟、索引、SEO 和迁移验证通过。
- node tests/browser-check.cjs：320 / 390 / 768 / 980 / 1440 宽度无水平溢出，搜索、选曲、真实内容随机、手机导航、键盘、减少动态效果通过。
- 原生照片转场与 FLIP 降级、作者定位、内容深链接、文本转义、内容源单独失败且其他空间继续工作通过。
- 原创静音 WAV 验证真实 play/pause、进度时钟、片段 offset、歌词高亮、持续手动阅读和恢复、音量、循环、Space、音源销毁。
- 80 本书的即时定位、长标题/长短评的书内分页、手机书名/作者/短评、混合横竖照片、照片浏览器 Back / Forward 和放大细节通过。
- 18 条记录的年份/关键词筛选、搜索清除条件、图片失败重载入口通过。
- 无未捕获页面异常，无本地资源 404。测试注入的数据均在路由内存，content/ 未被测试写入。

## 边界

浏览器自动回归中的 Apple iframe 与远端封面使用测试替身，不把它们当作实际第三方播放成功证明。实际浏览中 Apple iframe 在等待 15 秒后仍未显示可读播放控件；没有捕获到请求失败，但这不等于播放成功。重载和官方外链可用。未使用登录账号验证完整订阅曲目、未验证所有地区网络。没有真实电影、书籍和照片可用于内容审美判断，使用明确标识的原创几何夹具验证结构。桌面 Edge 与手机视口/触屏模拟经过测试；未在实体 iPhone Safari 或实体 Android 上测试。

## 复现

开发依赖仅维护阶段使用，线上仍无框架/构建依赖。运行 README 中检查命令。PLAYWRIGHT_MODULE 可指向已安装模块；BROWSER_CHANNEL 默认 msedge。SCREENSHOT_DIR 设置后输出书页/照片夹具截图。静音音频与原创图形不得替换为正式收藏。

## 性能抽样与边界

本地服务器，Edge，390 × 844，4 倍 CPU 降速：DOMContentLoaded 435ms，初始站内资源约 191KB（含移动首屏肖像），采样结束持续动画数 0；采到三次长任务 290/134/110ms。此为一次开发环境抽样，包含本机和浏览器启动开销，不是网络实机 Core Web Vitals 或所有设备的保证。

首屏肖像本地 WebP、preload/fetchpriority high；非首屏图片 lazy、尺寸与 srcset；各空间 content-visibility；没有轮询计时的假歌词、无限粒子或持续 requestAnimationFrame 循环。动效以 transform/opacity 为主。没有网站运行框架依赖。

本次自动浏览器验证为 Windows Edge，并未运行真实 iPhone Safari。代码保留不支持 View Transition 的后备实现，仍建议有实机后再补 iOS/Android 网络体验抽查。

## 内容和播放边界

电影、书仍为设计留白，暗房没有真实照片；不伪造站主经历。它们不参加随机和搜索。现有真实内容为五首曲目与一条记录。

现有商业歌曲只能使用官方嵌入，平台操作不伪造为本站自定义控制；完整自定义音频播放需要用户提供明确允许公开播放和静态分发的录音，或后续正式接入 MusicKit。歌词权限单独处理。详见 MUSIC-PROVIDERS.md / ASSET-SOURCES.md / CONTENT-GUIDE.md。
